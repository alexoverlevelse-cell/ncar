# OlehDK — Telegram Mini App

**ПЕРЕД ЛЮБОЙ РАБОТОЙ**: Спроси у пользователя — какие папки/файлы менять и окей ли начинать. Не трогай без подтверждения.

**Проект**: Telegram Mini App для Олега (подбор авто, проверка, продажа каталога)
**Стек**: Next.js + Telegram SDK, Supabase (БД), Vercel

## Ключевые правила
1. Администратор — только Олег (права проверяются на сервере по Telegram ID)
2. Язык интерфейса — украинский
3. Секретные ключи только в env-переменных
4. Все опасные действия (удаление) требуют подтверждение
5. MVP: не больше 10 машин, без фильтров/пагинации

## Команды
- `npm run dev` — запуск
- `npm run build` — сборка
